# Neural Network Lexicon

The **Neural Network Lexicon** is a structured, Python-first reference of neural network concepts explained from first principles.

It is designed to help learners, practitioners, and educators understand **what neural networks actually compute**, not just how to use high-level libraries.

This lexicon complements long-form articles and hands-on implementations by providing **clear, reusable explanations of core concepts**, one concept per page.

---

## Why This Lexicon Exists

Neural networks are often taught in one of two problematic ways:

1. **Too abstract** — heavy math, little intuition  
2. **Too opaque** — high-level libraries with no explanation of what happens underneath  

This project exists to close that gap.

The goal is to make neural networks **understandable by inspection**, using:
- Plain language
- Conceptual explanations before math
- Minimal, framework-free Python examples
- Consistent structure across all topics

If you can explain a concept in simple Python, you truly understand it.

---

## What This Lexicon Is (and Is Not)

### This Lexicon **Is**
- A concept-by-concept reference (one idea per page)
- Python-first and framework-agnostic
- Focused on understanding computation, not APIs
- Suitable for beginners **and** experienced developers
- Designed for long-term reuse and expansion

### This Lexicon **Is Not**
- A TensorFlow or PyTorch manual
- A math textbook
- A collection of buzzword definitions
- A black-box “just trust the library” guide

---

## Structure and Design Philosophy

Each lexicon entry follows the **same canonical structure**:

- Short Definition
- Definition (expanded explanation)
- Why It Matters
- How It Works (Conceptually)
- Minimal Python Example
- Common Pitfalls
- Related Concepts

This consistency ensures that:

Concepts are easy to scan
Pages can be read independently
Cross-linking feels natural
The lexicon scales cleanly over time

## How to Use This Lexicon

You can use the Neural Network Lexicon in three main ways:

1. As a Companion to Articles

Articles link into the lexicon to explain specific terms without breaking narrative flow.
This allows articles to stay focused while readers can dive deeper when needed.

2. As a Standalone Reference

Each page is self-contained and can be read independently as a lookup reference.

3. As a Learning Path

Start with foundational concepts and progress gradually toward advanced architectures and training strategies.
